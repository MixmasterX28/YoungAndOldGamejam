# YoungAndOldGamejam

Dude Wiz: The Dungeon is een gamejam-project dat binnen drie dagen is ontwikkeld door mij, Felix Huiskamp en drie tweedejaars studenten die wij mochten begeleiden.

Het thema van de gamejam was “Young and Old.”

Onze game is een toegankelijke coöperatieve puzzelgame waarin twee spelers nauw moeten samenwerken om het einde van het level te bereiken. Beide spelers vervullen een unieke rol met bijbehorende mogelijkheden:

Rogue – De rogue is snel, kan dashen en beschikt over een double jump. Hierdoor kan deze speler gebieden bereiken waar de oudere wizard niet kan komen, en zo bijvoorbeeld deuren openen om de weg vrij te maken.

Wizard – De wizard gebruikt magie om platformen te verplaatsen en puzzels op te lossen. Door zijn leeftijd is hij langzamer en kan hij niet springen, waardoor samenwerking met de rogue essentieel is.

Controls:
Rogue 
A/D - Links en rechts
Spatiebalk - Springen
Q - Dash

Wizard 
< / > - links en rechts
K/L - Platform bestuur
